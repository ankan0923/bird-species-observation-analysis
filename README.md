# 🐦 Bird Species Observation Analysis

## 📌 Project Overview

This project analyzes bird species observations across **Forest and Grassland ecosystems** to understand biodiversity, habitat distribution, environmental conditions, and bird behavior.

The analysis combines bird observation data from multiple administrative units and provides an interactive **Streamlit dashboard** for exploring ecological patterns.

---

## 🎯 Project Objectives

- Compare bird diversity across Forest and Grassland habitats.
- Identify the most frequently observed bird species.
- Analyze species richness across administrative units.
- Examine bird habitat preferences.
- Study the influence of temperature, humidity, wind, and sky conditions.
- Analyze bird behavior using identification method, distance, sex, and flyover observations.
- Explore conservation-related indicators such as PIF Watchlist status.
